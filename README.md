Number Guessing Game

## Description
A simple Python game where the computer generates a random number between 1 and 10. The player tries to guess the number.

## Features
- Random number generation
- User input
- Win/Lose result
- Beginner-friendly project

## Technologies Used
- Python 

## How to Run
1. Install Python.
2. Run:
   python number_guessing_game.py
